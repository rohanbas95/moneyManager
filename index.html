Sync with GitHub

Keeps your phone, laptop and other devices in step using one file in your own private GitHub repository. Without it, everything stays in this browser only.

How to set it up (one time, about 5 minutes)
  1. On github.com, create a new repository (e.g. money-data) and choose Private.
  2. Open Settings → Developer settings → Personal access tokens → Fine-grained tokens and tap Generate new token.
  3. Under Repository access choose Only select repositories and pick your new repository.
  4. Under Permissions → Repository permissions set Contents to Read and write. Pick an expiry date and generate the token.
  5. Copy the token (it starts with github_pat_) and paste it below. On your other devices, open this app and enter the same details.
The token is saved only in this browser and can only reach that one repository.
